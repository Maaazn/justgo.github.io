# JustGo — مراجعة تكامل المحركات

## القرار التنفيذي

يبني JustGo محركه الخاص تدريجياً، ولا ينسخ محركاً كاملاً بلا تدقيق. يستخدم **v86** كموصل تشغيل اختياري متوافق مع الويب في المرحلة الحالية، ويستفيد من أفكار QEMU/TCG وBochs وTinyEMU كمرجع لتصميم المترجم والأجهزة. أما PCjs فيبقى مرشحاً محدوداً لمحاكاة PC تاريخي إذا قبلنا التزاماته الإضافية في واجهة العرض. لا تدخل أي صورة نظام أو برنامج تابع لطرف ثالث في المستودع لمجرد أن المحرك نفسه مفتوح المصدر.

| المحرك | الترخيص المعلن | الملاءمة لـJustGo | قرار الدمج |
|---|---|---|---|
| v86 | BSD-2-Clause؛ مع تبعيات لها إشعارات مستقلة | محاكي x86 للمتصفح مع WebAssembly وأجهزة PC أساسية؛ محدود لـ32-bit ومن دون تعدد الأنوية | موصل اختياري محتمل مع حفظ إشعاراته وتراخيص تبعياته |
| QEMU / TCG | QEMU GPLv2 ككل؛ TCG خليط BSD/MIT وأجزاء أخرى | مرجع قوي للمترجم الديناميكي والأجهزة، لكنه ليس مكوّناً جاهزاً للويب | مرجع هندسي؛ لا دمج مباشر قبل تدقيق ملفات المصدر والتزامات GPL |
| Bochs | LGPL-2.1 مع ملفات خاصة | مرجع صريح لمعمارية IA-32 والأجهزة والـBIOS | مرجع هندسي؛ أي نقل يستلزم التزام LGPL وإشعارات التعديل |
| TinyEMU | MIT؛ SLIRP بترخيص BSD مستقل | مفيد لفهم محرك صغير وبناء Emscripten، لكن مسار الويب الرسمي لا يقدم x86 متصفحياً جاهزاً | مرجع هندسي؛ لا يعتمد كنواة x86 حالية |
| JSLinux | TinyEMU تحت MIT، مع تراخيص مستقلة للصور والبرامج | مثال واقعي لتشغيل x86/x86_64 وLinux عبر الويب | مرجع معماري وتجريبي؛ لا تُنقل أي صورة أو برنامج من العروض من دون ترخيص مستقل |
| PCjs | MIT مع متطلب إشعار PCjs/Jeff Parsons؛ مواد أرشيفية لها تراخيص مستقلة | محاكاة JavaScript جيدة لأجيال PC القديمة وأجهزة 8088–80386 | مكوّن تاريخي محتمل فقط إذا قُبلت متطلبات العرض والإشعار |

## فصل المسؤوليات

| طبقة JustGo | الملكية والخطة |
|---|---|
| Core-16، الذاكرة، المقاطعات والكتل | تنفيذ JustGo واختباراته؛ لا يعتمد على نسخة من محرك خارجي |
| موصل WebAssembly التشغيلي | v86 اختياري مع الاحتفاظ بإشعارات BSD وتراخيص التبعيات |
| الترجمة الديناميكية | تصميم مستوحى من بنية QEMU/TCG، لا نقل لشيفرة QEMU أو ادعاء توافقها |
| الأجهزة التاريخية والتوثيق | تستلهم من مراجع Bochs وPCjs مع كتابة تنفيذ JustGo الخاص |
| صور الإقلاع والأنظمة | مصادر قانونية مستقلة، تحميل عند الطلب أو اختيار محلي؛ لا تدخل في Git افتراضياً |

## بوابة قبول أي مكوّن خارجي

لا يُضاف مكوّن إلا بعد تسجيل المصدر الرسمي، الترخيص، ملف الإشعارات، طريقة تضمين المصدر أو النسخ الديناميكي، الأصول التابعة، أثره على حجم الحزمة، واختبارات واضحة لعزله أو إزالة تفعيله. لا تعني رخصة المحرك أن صور الضيوف أو البرامج التي يمكن تشغيلها مرخصة تلقائياً.
