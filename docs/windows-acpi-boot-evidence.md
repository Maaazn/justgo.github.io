# دليل إقلاع Windows المحلي — نقطة ACPI

## الملاحظة

في اختبار محلي بوسيط ISO اختاره المستخدم، وبعد ربطه تلقائياً كـ CD-ROM، عرض v86/SeaBIOS **Windows Boot Manager** بدلاً من فشل قراءة CD-ROM السابق. ظهرت الرسالة التالية:

```text
0xc0000225
Info: Windows failed to load because the firmware (BIOS) is not ACPI compatible.
```

## ما يثبته الدليل

يثبت الدليل أن المتصفح قرأ الوسيط المحلي، وأن BIOS وصل إلى مرحلة boot manager الخاصة بالوسيط. لا يثبت أن Windows أقلع، ولا يثبت توافقاً مع Windows أو ACPI أو التخزين أو التعريفات بعد هذه النقطة.

## الأثر الهندسي

المسار التالي هو فحص حدود ACPI في firmware والمحرك المستخدم، وليس تغيير نوع الوسيط أو زيادة ذاكرة الضيف. يوفر v86 خيار `acpi` تجريبياً في عقده وفي صفحة debug الخاصة به؛ أضيف الخيار إلى جلسة JustGo ويُفعّل افتراضياً لمسار Windows Boot Manager. لا تُضمّن صورة Windows أو مفتاح أو لقطة المستخدم في المستودع أو GitHub Pages.
