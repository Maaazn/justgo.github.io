# JustGo — مصفوفة توافق الإدخال والمخرجات

هذه المصفوفة تفصل بين السلوك الذي اختبرته وحدات JustGo آلياً والسلوك الذي لا يمكن إثباته إلا على جهاز ومتصفح حقيقيين.

| المسار | الاختبار الآلي | الحالة | الاختبار الميداني المتبقي |
|---|---|---|---|
| OUT إلى منفذ غير معروف | يسجل التشخيص ويستمر الضيف | مكتمل | تدقيق منافذ برنامج ضيف حقيقي لاحقاً |
| framebuffer RGBA | ذاكرة A0000 وقراءة/كتابة البكسل | مكتمل | ربط Canvas ومقارنة إطار مرئي |
| لوحة المفاتيح PS/2 | queue ومنافذ 8042 | مكتمل | تجربة مفاتيح فعلية في متصفح ميداني |
| ماوس PS/2 | ACK وstreaming وحزم الحركة والأزرار | مكتمل | ماوس حقيقي على desktop وiPad |
| Pointer Events | تحويل وفقدان التركيز في وحدة نقية | مكتمل | Safari iPhone/iPad فعلي |
| Pointer Lock | خيار desktop فقط | مكتمل من جهة كشف القدرة | متصفح سطح مكتب فعلي |
| WebHID | لا يطلب جهازاً قبل استدعاء صريح | مكتمل | Chrome/Edge مع جهاز HID يختاره المستخدم |
| WebUSB | لا يطلب جهازاً قبل استدعاء صريح | مكتمل | Chrome/Edge مع جهاز USB يختاره المستخدم |

## حدود صريحة

لا تعني واجهة WebHID أو WebUSB أن الضيف حصل على متحكم USB كامل. الحصول على جهاز من المتصفح يسبق مراحل مستقلة: وصف الجهاز، endpoints، نقل البيانات، ومتحكم USB ضيف. ولا تدّعي JustGo وجود هذه المراحل قبل تنفيذها واختبارها.

لا تدعم Safari على iOS واجهات WebHID أو WebUSB بصورة يعتمد عليها هذا المشروع؛ يبقى Pointer Events واللمس وPS/2 المحاكى أساس تجربة iPhone/iPad.[1] [2]
