# JustGo — خريطة توسع هندسية

## المبدأ

سجل JustGo الحالي يقارب **2,115 سطراً** عبر الشيفرة والاختبارات والوثائق. لا يُعامل رقم 500,000 كسطر مطلوب بحد ذاته؛ بل كسقف محتمل لا يتحقق إلا عندما تتوسع التغطية الفعلية للمعالج والأجهزة والتوافق والاختبارات. يجب أن تكون كل وحدة قابلة للبناء والفحص والإزالة مستقلة، وأن تملك حدوداً واضحة ومرجعاً قانونياً لأية تبعية خارجية.

## خريطة الطبقات

| الطبقة | المسؤولية الفعلية | نطاق تقريبي صحي عند النضج | شرط الدخول إلى المشروع |
|---|---|---:|---|
| ISA وCPU | فك التعليمات، السجلات، الأعلام، الاستثناءات، real/protected mode | 25k–70k | اختبار تعليمة مقابل نموذج مرجعي |
| الذاكرة والترجمة | segmentation، paging، TLB، IR، cache كتل، إبطال وترجمة إلى WebAssembly | 30k–85k | اختبار تطابق مع المفسر وقياس قابل لإعادة التشغيل |
| المقاطعات والـfirmware | PIC/PIT/DMA وBIOS خاص بالمشروع وأحداث الإقلاع | 20k–55k | لا نسخ لملفات BIOS أو firmware ذات رخصة مجهولة |
| شرائح الأجهزة | PCI، IDE/AHCI، USB، PS/2، ACPI والواجهات اللازمة للضيف | 45k–120k | عقد جهاز واختبارات حالة/زمن لكل جهاز |
| العرض والصوت | VGA/SVGA، framebuffer، compositing، إخراج الصوت | 35k–90k | اختبار مخرجات ثابتة ومقارنة صور مرجعية |
| الوسائط والتخزين | ISO/IMG محلي، طبقات قرص، snapshots، حصص الذاكرة والتحقق من الصيغ | 18k–45k | عدم رفع الملفات وعدم تضمين وسائط نظام خاصة |
| الإدخال وإتاحة الوصول | mouse/keyboard/touch، iOS fallback، اختصارات، توزيع لوحة المفاتيح | 12k–35k | اختبار iOS وdesktop واستخدام Pointer Lock كتحسين فقط |
| العزل والخصوصية | سياسات الشبكة، حدود الذاكرة، تنظيف الجلسة، إقرارات الوسائط | 10k–35k | اختبار رفض وتحليل طلبات الشبكة |
| الاختبارات والأدوات | corpora تعليمات، integration، benchmarks، fuzzing، أدوات تحليل صور | 70k–170k | كل زيادة شيفرة في المحرك تقابلها اختبارات ذات معنى |
| الوثائق والأمثلة | عقود الوحدات، إشعارات التراخيص، أدلة تشغيل ومصفوفة توافق | 20k–60k | مراجعة المصدر والترخيص لكل بيئة أو مكوّن |

يمكن أن يصل هذا النطاق إلى أكثر من 500k سطر عندما تكون الطبقات مكتملة حقاً، خصوصاً مع الاختبارات وأدوات التشخيص. ولكن لا يبدأ تنفيذ طبقة جديدة قبل أن تمر السابقة باختبارات التوافق والقياس؛ الحجم الناتج نتيجة تغطية فعلية وليس هدفاً يسبقها.

## المسار المرحلي

| المرحلة | ما يثبت أنها حقيقية | ما لا تدعيه |
|---|---|---|
| Core-16 الحالية | CPU صغير وذاكرة ومنافذ ومقاطعات وكتل مخزنة مع اختبارات | ليست نواة Windows |
| 386 Transition | protected mode، descriptors، paging وأجهزة PC أبسط | لا تعني إقلاع Windows 7/10 تلقائياً |
| Guest Foundation | تخزين وVGA وPS/2 وIDE وصورة مفتوحة المصدر تخضع لاختبار إقلاع | ليست دعم برنامج تجاري |
| Compatibility Lab | مصفوفة صور قانونية يختارها المستخدم محلياً ونتائج مرصودة | لا توزع أي ISO أو مفتاح |
| Production Candidate | حدود موارد، عزل، تشخيص، واجهة iOS وdesktop، مراجعة تراخيص | لا تعد بالمنافسة مع خدمة بعيدة قبل المقاييس |

## قاعدة التكامل الخارجي

لا تدخل شيفرة أو محرك خارجي إلا داخل طبقة تكامل مستقلة مع ملف `NOTICE` وإثبات المصدر والترخيص. يستخدم v86 كموصل منفصل وفق BSD-2-Clause في المرحلة الحالية، بينما تظل QEMU/TCG وBochs وTinyEMU وJSLinux مراجع معمارية إلى أن يراجع كل ملف وتبعية وشروط نشره.[1] [2] [3] [4]
